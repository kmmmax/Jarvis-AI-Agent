JARVIS AI AGENT

ИИ-ассистент с поддержкой локальных нейросетей (через Ollama), памятью диалога и набором инструментов (функций) для взаимодействия с внешним миром и файловой системой.

======================================================================
УСТАНОВКА И ЗАПУСК
======================================================================

1. Убедитесь, что у вас установлена Ollama и загружена нужная модель (по умолчанию qwen3.5-9b-8k).
2. Создайте и активируйте виртуальное окружение:
   python -m venv .venv
   source .venv/bin/activate  (Для macOS/Linux)
3. Установите зависимости:
   pip install -r requirements.txt
4. Запустите ассистента:
   .venv/bin/python main.py

======================================================================
ВАЖНО: ПРОКСИ ДЛЯ РАБОТЫ ПОГОДЫ (ЕСЛИ ВЫ В РОССИИ)
======================================================================

Если вы находитесь в России, сервера, с которых API погоды (wttr.in) собирает данные, могут быть заблокированы или работать нестабильно. Для корректной работы инструмента get_weather рекомендуется использовать прокси.

Как настроить прокси:
В файле tools/get_weather.py найдите переменную PROXIES и укажите ваш прокси в формате:
PROXIES = {"http": "http://IP_АДРЕС:ПОРТ", "https": "http://IP_АДРЕС:ПОРТ"}

(Если прокси SOCKS5, используйте socks5://... и убедитесь, что установлена библиотека requests[socks]).

======================================================================
ДОСТУПНЫЕ ИНСТРУМЕНТЫ (ФУНКЦИИ)
======================================================================

Ассистент умеет не только болтать, но и выполнять действия. Вот полное описание того, что он умеет:

1. get_current_time
   Что делает: Возвращает текущее время и дату в указанном часовом поясе.
   Параметры:
   - timezone (опционально): Название часового пояса в формате IANA (например, Europe/Moscow, America/New_York). Если не указан, берется системная таймзона компьютера.
   Особенности: Умеет определять локальную таймзону автоматически (через библиотеку tzlocal).

2. get_weather
   Что делает: Узнает текущую погоду и прогноз максимальной температуры на сегодня.
   Параметры:
   - city_name (опционально): Название города (на английском, например, Moscow, London). Если не указан, используется дефолтный город из настроек.
   Особенности: Работает через wttr.in. Если вы в России, обязательно настройте прокси (см. раздел выше), иначе запрос может зависнуть.

3. list_dir
   Что делает: Показывает список файлов и папок в указанной директории.
   Параметры:
   - dir_path (опционально): Путь к папке (например, ., tools, /home/user). По умолчанию — текущая папка.
   - limit (опционально): Максимальное количество элементов для вывода (по умолчанию 50).
   Особенности: Выводит сначала папки, потом файлы. Если элементов больше лимита, предупреждает об этом и показывает, сколько скрыто.

4. read_file_content
   Что делает: Читает и возвращает текстовое содержимое файла.
   Параметры:
   - file_path (обязательно): Путь к файлу (например, main.py, system_prompt.txt).
   - limit_of_chars (опционально): Сколько символов прочитать за один раз (по умолчанию 6000).
   - offset (опционально): С какого символа начать чтение (по умолчанию 0).
   Особенности:
   - Если файл больше лимита, выводит предупреждение [ALERT] и указывает, какой offset передать в следующий раз, чтобы дочитать.
   - Не читает бинарные файлы (картинки, архивы).
   - Защищен от чтения огромных файлов, чтобы не переполнить контекст нейросети.

======================================================================
УПРАВЛЕНИЕ КОНТЕКСТОМ (ПАМЯТЬ)
======================================================================

Нейросеть не может запомнить бесконечно много текста. У ассистента есть защита от переполнения:
- Лимит токенов: 8192 токена (настраивается в main.py).
- Автоматическая обрезка: Если история диалога становится слишком длинной, старые сообщения удаляются целиком (парами "вопрос-ответ"), чтобы освободить место.
- Аварийный сброс: Если даже последний вопрос + результаты инструментов не влезают в лимит, история сбрасывается до системного промпта и текущего вопроса. Ассистент предупредит вас об этом красным текстом.

======================================================================
РЕЖИМЫ РАБОТЫ
======================================================================

1. Chat (Режим чата): Бесконечный цикл с сохранением истории. Ассистент помнит, о чем вы говорили ранее, и может использовать инструменты.
2. Generate (Режим генерации): Один запрос — один ответ. Без памяти и без использования инструментов. Подходит для простых вопросов.

Для выхода из программы введите exit, stop или нажмите Ctrl+C.
